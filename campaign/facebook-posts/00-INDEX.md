# Facebook Posts — Paste-Ready

Every `.txt` file in this folder contains **only the post text**. Open it, select all,
copy, paste into Facebook. Nothing to clean up, no markdown to strip.

Files ending in `.comment.txt` are the **first comment** for that post. Post the main
text, then immediately add the comment. Links go in the comment, never in the post body —
Facebook suppresses reach on posts containing outbound links.

Anywhere you see `[YOUR CONTACT LINK]`, swap in your real intake link before posting.

---

## How to post

1. Copy the `.txt` file contents into a new Facebook post.
2. Attach the image described below (build it from `../08-GRAPHICS-BRIEFS.md`).
3. Paste the alt text into Facebook's alt text field — Edit photo → Alternative text.
4. Publish, then immediately post the `.comment.txt` as the first comment if there is one.
5. Check back in the first two hours and answer every reply. Early comment velocity is
   what drives reach.

**Best posting times, Eastern:** 6:30–7:30am (before day shift), 2:30–3:30pm (shift
change), 9:30–11:00pm (after second shift — usually your best window). Avoid mid-morning.

**Never put a link in the post body.** Say "link in the first comment" instead.

## Before you publish anything

Run the checklist in `../09-LEGAL-SAFETY.md`:

1. Does it name your former employer or any facility? Cut it.
2. Does it describe your own case? Cut it.
3. Does every number have a source you can link? Add it.
4. Could a resident be identified? Cut it.
5. Did someone give written permission for their words? Get it.
6. Would you be fine with opposing counsel reading this aloud? If not, cut it.
7. Are you angry right now? Schedule it for tomorrow.
